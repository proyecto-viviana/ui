## The fix

`scripts/check-certified-case-floor.mjs:88` now spawns `vp`, the form
`scripts/check-peers.mjs:100` already uses:

```js
execFileSync("vp", ["exec", "playwright", "test", "e2e/certified", "--list", "--reporter=json"], …)
```

`scripts/` now has no bare-`pnpm` call site at all — `grep -rn '"pnpm"'
scripts/*.mjs` returns only the `vp exec pnpm peers` line in `check-peers.mjs`,
which is `vp` driving the tool. The `.github/workflows/` lines are out of scope
and untouched.

Green on the fix:

```
$ vp run guard:certified-case-floor
certified case floor: 73 files, 2177 cases, none below the floor.   EXIT=0
```

Since both runs are green, the proof that matters is the call site, not the
exit code: the guard no longer asks a package manager for permission before
reading a listing.
