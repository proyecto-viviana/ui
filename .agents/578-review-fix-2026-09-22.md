## 3 (medium) — anchored only with `$`

Real in substance, wrong in the suggestion. The suggested anchor was
`^certified/tabs\.certified\.spec\.ts …$`, and it matches nothing:

    failureHaystack(failure) = `${failure.file} ${failure.title}`

`file` is `relativeSpecFile(...)` of the file the case is **declared** in — the
driver's, for a driver-declared case — while the spec path is the head of the
title. Measured, the tabs haystack is

    e2e/drivers/events.ts certified/tabs.certified.spec.ts › D4 event sequence — Tabs › horizontal-regular · arrow-next-from-selected

Every entry is now `^…$` over that whole string, and the loader refuses, as
`invalid-pattern`, a pattern that is not anchored at both ends or that names no
`.certified.spec.ts` file. A test pins the reading, so the next person does
not write the anchor that reads right and matches nothing.
