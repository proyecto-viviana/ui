`Internal Server Error` is the generic message a production build leaves behind,
so the preview cannot name the cause. `vp dev` is not the way to get the real
one either: starting it triggers a rebuild of the workspace `dist` directories
and the SSR graph then reads them mid-write, which produces a different and
entirely spurious set of `Failed to load url …/dist/…` errors. Every file it
names does exist. Whoever takes this should build with server sourcemaps, or
catch inside the route, rather than trust either server's console.
