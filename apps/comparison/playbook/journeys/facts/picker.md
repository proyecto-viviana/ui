# Picker / Select — user-observable facts

Pin: Adobe `react-spectrum` `f56660b`. RAC `Select` + S2 `Picker`. Docs: `react-aria-components/docs/Select.mdx` is absent; `packages/dev/s2-docs/pages/react-aria/Select.mdx` is examples/API only (no keyboard table). S2 mobile tray is a commented TODO in S2 `Popover.tsx` (not live).

Conventions: `[RAC]` React Aria Components Select. `[S2]` Spectrum 2 Picker (wraps RAC Select). `[Aria]` `useSelect` / `useMenuTrigger` / list/overlay hooks. `[Stately]` `useSelectState`. `[Hidden]` HiddenSelect. `[Tester]` `@react-aria/test-utils` SelectTester (canonical protocols). `source:` rows are source-only branches tests do not cover. Select uses **real DOM focus** on options (`shouldUseVirtualFocus` unset). List `selectOnFocus` is false (selectionBehavior `'toggle'`). List `shouldFocusWrap` is false (unset). `TYPEAHEAD_DEBOUNCE_WAIT_MS = 1000`.

Unless noted, `selectionMode="single"`, `shouldCloseOnSelect` defaults to `true` for single and `false` for multiple.
