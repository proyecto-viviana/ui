## Unclassified / not user-observable as specified

These source branches exist but could not be turned into a closed journey with a unique expected observation from RAC/S2 ComboBox as shipped:

1. **`completionMode = 'complete'` / `aria-autocomplete: both`** — commented TODO in `useComboBox.ts:135,524`. Always `'suggest'` + `aria-autocomplete='list'`. Row FIL024 records the gap.
2. **S2 mobile tray** — `s2/src/Popover.tsx:215-218` TODO ("reverted this until we have trays"). S2 ComboBox never mounts a tray, tray input, tray dismiss buttons, or tray clear button. S1 `MobileComboBox` is out of scope. Row TCH007 / OC050.
3. **`inputMode`** — forwarded by `useTextField` only if the consumer sets it. RAC/S2 ComboBox set no default. Row FRM022 / TCH009.
4. **`Alt+ArrowDown` on the input** — APG lists it; RAC registers `Alt+ArrowDown` on the _trigger button_ (`useMenuTrigger.ts:102-107`), not the input. Input opens with plain ArrowDown/Up. Row OC029–OC030.
5. **Multi-select VoiceOver `selectedAnnouncement`** — `useComboBox.ts:452` TODO "do we need to do this for multi-select?". Single-select Apple announcement only (ARIA021).
6. **`isVirtualized: true` on ComboBox's own `useSelectableCollection`** — passed in `useComboBox.ts:181` with comment "Prevent item scroll behavior", but `useSelectableCollection` does not destructure/use `isVirtualized` in its body (flag currently unused). Scroll-into-view still runs on the ListBox instance (NAV018–NAV019).
7. **Controlled `isOpen` / `defaultOpen`** — `useComboBoxState.ts:320-324` forces `isOpen: undefined, defaultOpen: undefined` on `useOverlayTriggerState`. Open state is not a public RAC ComboBox control. Row TIM012.
8. **Home/End/PageUp/PageDown exact caret vs virtual-focus interaction** — collection handlers are chained only while `isOpen` (NAV009–NAV012). Listed tests never press Home/End/Page*. Pixel distance for Page* depends on `listBoxRef` layout. Journeys should assert `aria-activedescendant` identity, not pixels.
9. **Listbox-internal scroll vs close** — `scrollRef` is the listbox (OV017). No listed test scrolls the listbox itself; inferred that because the listbox is not an ancestor of the trigger, `useCloseOnScroll` ignores it. Confirm in a journey if porting overlay close.
10. **S2 chevron `rotate: 90` in RTL** — no `direction` branch (RTL008). Visual only.

`react-spectrum/packages/react-aria-components/docs/ComboBox.mdx` is not present; keyboard/`menuTrigger`/`allowsCustomValue` copy was read from `packages/dev/s2-docs/pages/react-aria/ComboBox.mdx` (same RAC surface).
